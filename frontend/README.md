# Frontend Agente MEI

SPA construída com React + Vite + Tailwind para consumir os serviços do backend Agente MEI.

## Requisitos

- Node.js 18+
- pnpm, npm ou yarn

## Configuração

```bash
cp .env.example .env
# ajuste VITE_API_BASE_URL se necessário
npm install
npm run dev
```

Principais rotas:

- `/login` e `/register`
- `/dashboard`
- `/documents`
- `/agent`
- `/billing`
